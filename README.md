# Ahmad Ali — Portfolio

A dark, premium editorial portfolio inspired by Velmax / Valmax. Built with HTML, CSS, and vanilla JavaScript.

## Live Demo
https://ahmadali-01.github.io/portfolio/

## Sections
- **Hero** — oversized headline, availability pill, stats row, scroll cue
- **Ticker** — scrolling skills marquee
- **About** — floating portrait, bio, quick facts
- **Work** — six projects with animated mock browser previews
- **Services** — three numbered columns
- **Process** — five italic-numbered steps
- **Voices** — three testimonials
- **Contact** — underlined form fields on a dark panel

## Typography
- **Inter Tight** — headings and body (modern, tight, editorial)
- **JetBrains Mono** — labels, numbers, section markers

## Color
Near-black canvas + warm copper accent. No blue, no purple.

| Role    | Hex       |
|---------|-----------|
| Ink     | `#0A0A0B` |
| Surface | `#111113` |
| Copper  | `#D4A574` |
| Text    | `#EDEDEB` |

## Features
- Fixed header with scroll progress line
- Scroll spy for active section
- Reveal animations with staggered delays
- Subtle grain texture overlay
- Marquee ticker
- Animated mock browser previews
- Underlined form fields (no boxes)
- Fully responsive, accessible (skip link, ARIA, reduced motion)
